# Medical Aesthetic Prompt Library

The application ships with four local prompt collections instead of the previous general-purpose third-party prompt feeds:

| Collection                     | Purpose                                                                                                        |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Pre-treatment standard photos  | Normalize angle, framing, lighting, expression, and background without changing anatomy                        |
| Post-treatment standard photos | Apply only a named, conservative treatment change while locking identity and capture conditions                |
| Post-treatment everyday photos | Reuse the same identity and treatment result in believable phone-photo situations without extra beautification |
| Quality review                 | Repair identity drift, mismatched capture conditions, plastic skin, and exaggerated outcomes                   |

The prompts preserve pores, fine lines, minor asymmetry, age, skin tone, and identifying marks. They explicitly reject beauty filters, skin smoothing, face slimming, favorable relighting, and changes outside the treatment area.

These images are simulations, not clinical records or outcome guarantees. Use only authorized portraits, retain the original files, disclose material edits, and label simulated outcomes clearly when publishing them. Real before/after documentation should follow a clinic's standardized photography protocol and applicable advertising rules.

Each collection is bundled as standard JSON under `web/public/prompts`, so it works locally without relying on an external prompt registry. Settings still supports optional custom JSON sources.
